# Security policy

Please do not report security vulnerabilities in public issues or pull requests.
On the [security advisories page](https://github.com/daviesevan/mint/security/advisories),
select **Report a vulnerability** to share details privately with the maintainers.
If that option is unavailable, open an issue asking for a private contact without
including any vulnerability details.

Include affected versions, steps to reproduce, and the potential impact. Do not
include real customer data or credentials. Please allow time for investigation
and a fix before disclosing the issue publicly.
