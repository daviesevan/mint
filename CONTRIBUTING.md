# Contributing

Contributions and feedback are welcome. For security issues, follow the private
reporting process in [SECURITY.md](SECURITY.md), not a public issue.

1. Discuss significant changes in an issue before starting work.
2. Create a branch and open a pull request describing the change and how it was
   tested. Sign all commits so GitHub can verify them; see
   [GitHub's commit signing guide](https://docs.github.com/en/authentication/managing-commit-signature-verification/signing-commits).
3. Run the checks in the [README](README.md#checks). All CI checks must pass
   before merging, and maintainers may request changes during review.

By submitting a contribution, you agree to license it under the project's
[AGPL-3.0-only license](LICENSE).
